# Wedding Tracker

Installable phone app for the run-up to 10 October 2026.

- **Home** – countdown, hour-by-hour rain risk for the day (10:00–midnight), weather for every day up to the wedding, and tips worked out from the forecast (sunset/golden hour, evening temperature, wind for anything outdoors).
- **Tasks** – checklist grouped by when it needs doing (this week, Mon–Thu, Friday set-up, Saturday morning, after).
- **Money** – what's still to pay.
- **The Day** – running order with times, and key contacts you can tap to call.

Weather comes from Open-Meteo (free, no key) for Hollywood/Wythall and refreshes every 30 minutes. Everything else is stored on the phone only; use *Back up data* on The Day tab to save a copy.

## Install on Android
1. Repo **Settings → Pages** → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
2. Open `https://tribbles69.github.io/Wedding-tracker/` in Chrome.
3. Menu ⋮ → **Add to Home screen / Install app**.
